# HederaSM

**HederaSM** is a private SaaS platform and digital ecosystem focused on automation, subscription management, and a modern user experience.

This repository contains public documentation only. The codebase is **closed-source** and maintained privately.

---

## Tech Overview

**Frontend**
- Angular
- TailwindCSS
- shadcn/ui (Angular equivalent)
- UI inspired by React Bits components

**Backend**
- Node.js / Express
- Sequelize ORM
- MySQL
- JWT authentication
- Gmail API integration
- SmartMail rule engine
- Stripe subscription system

**Infrastructure**
- Hetzner Cloud (server + database)
- Nginx reverse proxy + SSL
- PM2 process manager
- Cloudflare (DNS + CDN + security)
- Automatic backups + Fail2ban + UFW firewall
