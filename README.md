# 🌿 HederaSM

**HederaSM** is an upcoming SaaS platform and digital ecosystem focused on automation, subscription management, and a modern UI.

- Public repo for docs, roadmap, and updates  
- Codebase is **private** (closed-source) during active development

## 🚀 Tech Overview
- **Frontend:** React + Tailwind + shadcn/ui + React Bits
- **Backend:** Node.js / Express + Sequelize
- **Database:** MySQL (AWS RDS)
- **Deploy:** Vercel + AWS (API Gateway/Lambda)
- **Integrations:** Stripe, Gmail (SmartMail)

## 📅 Status
🚧 In active development (private). Public updates land here.
